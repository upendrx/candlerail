Quick start

Test your trading idea on years of real prices, before you risk a cent.

candlerail is a free app that runs on your own computer. Pick a ready-made strategy or build one with dropdowns, add sensible money management, and see honestly how it would have done.

Choose your system. The one-line installer downloads a ready-made program; building from source takes a few minutes longer and works on any machine Rust supports.

Build from source

Needs the Rust toolchain (free, about 5 minutes to install) and Git.

  1. Install Rust

    Download and run rustup-init.exe. If it asks, let it install the Visual Studio C++ build tools. Get Git from git-scm.com.

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

    macOS asks to install the command-line developer tools the first time; accept.

  2. Download and build
    git clone https://github.com/upendrx/candlerail cd candlerail cargo build --release
  3. Start it
    .\target\release\candlerail.exe serve
    ./target/release/candlerail serve

Your first fifteen minutes

Everything below happens inside the app, and each tab explains itself as you go.

1

Backtest a template

Open Strategies, pick one, press Backtest. Candles download free from Binance the first time and are cached.

2

Read the result

Look at max drawdown before return, compare with buy and hold, and read the warnings. They're written in plain words.

3

Pick candles on a chart

Open the Chart Lab, drag across a few candles you like, and see every time the same shape appeared and what came next.

4

Change a rule

Press Open in builder, change a number or a condition, and watch the plain-English summary update. Run it again.

5

Add money management

On Money management, pick a preset such as Elder's 2% and 6% rules and apply it. See what the limits changed.

6

Share it

Press Share this result. Anyone can load the file on the Community tab and re-run your exact test.

Chart Lab

Pick a setup straight off the chart

Drag across the candles you'd trade. The lab turns their shape into rules, marks every other time it happened with what price did next, and backtests it on any timeframe or coin in one click.

  • Swing zigzag with higher highs and lower lows labelled
  • Mark swings yourself; it finds the setting that sees them your way
  • Draw levels and use them in rules
  • Compare 5m to 1d, or BTC to XRP, side by side

Trade what the candles say

Build strategies from raw price: candle shapes, swing support and resistance, market structure, and yesterday's, last week's or last month's levels on any timeframe.

  • 13 candle patterns, drawn and explained
  • Rules as plain arithmetic, like lower_wick > 2 * body

Money management

Size every trade like a professional

Calculators for shares, crypto, forex lots and futures contracts; the rules famous traders use; and a simulation of 2,000 possible futures for your strategy.

  • Fixed-fractional risk, Kelly, R-multiples
  • Daily and monthly loss limits, drawdown circuit breaker
  • Guidance for each market and on spreading risk
Honest results

Numbers you can trust

Orders fill at the next open, stops win ties, every trade pays fees and slippage, and leveraged trades can be liquidated. The report compares against buy and hold and checks for overfitting.

Community

Share strategies with their real profit and loss

A share file holds the strategy and its recorded result. Anyone can re-run it on the same data and see whether the numbers hold, losses included.

If something goes wrong

The common problems, and how to fix them.

"candlerail" is not recognized / command not found

The install folder isn't on your PATH yet. On Windows, open a new PowerShell window. On macOS or Linux, run the export PATH=... line the installer printed, or start it with the full path: ~/.local/bin/candlerail serve.

Windows says it protected my PC

SmartScreen warns about new programs that haven't been downloaded by many people yet. Click More info, then Run anyway, or build from source instead.

macOS says the app can't be opened

This happens if you downloaded the archive with a browser. Run xattr -d com.apple.quarantine ~/.local/bin/candlerail once, or use the one-line installer, which doesn't trigger it.

The address is already in use

Another program is using port 8787. Pick a different one: candlerail serve --listen 127.0.0.1:9000, then open http://127.0.0.1:9000.

Candles won't download

Binance's public market-data API is blocked in some countries and networks. Upload a CSV of candles in the builder instead (any market works), or point to another mirror with --binance-api.

Can I use it for stocks, forex or futures?

Yes. Export candles as CSV (time, open, high, low, close, volume) from your broker or charting tool and upload the file in the builder. See Getting started for the format.

What does it need?

Any 64-bit computer from the last ten years, about 10 MB of disk plus room for cached candles, and a browser. No account, no API key, no internet connection beyond downloading candles.

How do I update?

Run the install command again. Your cached candles and saved strategy files are kept.

Simulation only. candlerail never places real orders. Past results don't predict future ones, and most traders who use leverage lose money. Nothing here is financial advice.
